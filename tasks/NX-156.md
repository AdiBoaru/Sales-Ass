# NX-156 - Fallback localizat RO/HU/EN pentru pipeline si web chat

**Owner:** TBD · **Faza:** P1 · **Track/Wave:** AI Quality / Reliability · **Branch:** `fix/NX-156-localized-fallbacks` · **Complexitate:** S-M · **Estimare:** 4-6h

## Goal

Toate fallbackurile vizibile clientului respecta limba conversatiei si canalul. In special, `fallback_stage` nu mai raspunde hardcodat in romana cand conversatia este EN/HU.

## Business Context

Fallbackul apare exact cand sistemul nu a inteles, LLM-ul nu poate raspunde sau ruta este incompleta. Daca in acel moment userul primeste romana intr-un flow EN/HU, increderea scade imediat. Pentru webwidget, fallbackul este parte din experienta de productie.

## Scope

1. Localizeaza fallbackul final din pipeline:
   - RO;
   - EN;
   - HU.

2. Standardizeaza fallbackuri pentru:
   - no match / no result;
   - LLM unavailable;
   - tool/search unavailable;
   - business unavailable;
   - rate limit / budget exceeded;
   - handoff unavailable pe web;
   - order/return pe web anonim.

3. Aliniaza cu contractul web:
   - `content` nu este gol;
   - `products` poate fi gol;
   - optional `error_code` stabil pentru frontend;
   - mesajele sunt scurte si actionabile.

## Implementation Steps

1. Introdu map de fallbackuri localizate, preferabil intr-un modul mic, nu hardcodat in fiecare stage.
2. Actualizeaza `fallback_stage` sa foloseasca `ctx.language` / `conversation.locale`.
3. Actualizeaza calea `/web/chat` pentru erori de business daca frontendul are nevoie de payload normalizat.
4. Adauga teste RO/EN/HU pentru fallback final.
5. Adauga cazuri golden pentru EN/HU fallback.

## Acceptance Criteria

- [ ] Conversatie RO fara route produce fallback RO.
- [ ] Conversatie EN fara route produce fallback EN.
- [ ] Conversatie HU fara route produce fallback HU.
- [ ] `/web/chat` nu intoarce payload gol pentru fallback/error controlabil.
- [ ] Rate/budget/business unavailable pot fi diferentiate de frontend prin status sau `error_code`.
- [ ] Golden cases includ minim 1 fallback EN si 1 fallback HU.
