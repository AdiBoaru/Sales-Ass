# NX-219 — Conversation action kernel: follow-up-uri de recenzii

## Problemă

Un follow-up generic precum „Vezi recenzii” intra din nou în bucla LLM, care putea alege arbitrar
primul produs și emitea mai multe apeluri concurente pe aceeași conexiune asyncpg. Rezultatul era
repetitiv, uneori incomplet și nu răspundea la acțiunea cerută.

## Definition of Done

- [x] Apelurile de tool din același tur sunt serializate la marginea care deține conexiunea DB.
- [x] Intenția de recenzii funcționează generic în RO/EN/HU pentru produse deja afișate.
- [x] Un singur produs sau un produs identificat prin nume/ordinal este rezolvat fără LLM.
- [x] Un follow-up ambiguu pe mai multe produse cere explicit produsul, fără alegere arbitrară.
- [x] Răspunsul folosește numai datele reale de recenzii și rating din catalog.
- [x] Lipsa datelor produce un răspuns onest; nicio cale nu rămâne fără răspuns.
- [x] Fetch-ul rămâne tenant-scoped prin interogarea existentă get_products_by_ids.
- [x] Există kill-switch și teste pentru regresia de concurență și rezolvarea follow-up-ului.
